# Platsbanken Pendling – film och demo

Publicerad sida: https://kingkongola.github.io/platsbanken-pendling-film/

Enbart det färdiga bygget av en prototyp: film och en klickbar demo med sex
frysta, verkliga platsannonser och vägberäkning i webbläsaren
(OpenStreetMap, sydvästra Skåne). Ingen SCB-data: kopplingen mot
arbetsställeregistret visas med en tydligt märkt påhittad registerrad.
Källkoden finns i ett separat, privat repo. Kartdata © OpenStreetMap contributors.
